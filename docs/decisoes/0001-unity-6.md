# 0001: Unity 6000.5.10f1 em vez de 2022.3 LTS

**Data:** 27/10/2026 · **Status:** aceita

## Contexto
O GDD v1.0 citava Unity 2022.3 LTS ou 2023.x. O projeto "Escura" do Luis (desafio-unity), base técnica do grupo, já usa Unity 6000.5.10f1 com URP 2D, Light2D e Input System.

## Decisão
Todo o grupo usa **6000.5.10f1**. Settings de URP 2D, Renderer2D, Volume e Input System foram copiados do Escura.

## Consequências
- Scripts do Escura podem ser portados sem conversão de API (ex.: `Rigidbody2D.linearVelocity`).
- Ninguém atualiza a versão sem combinar com o grupo: abrir o projeto em outra versão reescreve arquivos de `ProjectSettings/` e gera conflito.
